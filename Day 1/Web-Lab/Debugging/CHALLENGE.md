# Debugging Detective — student brief

You have 22 minutes. Find the causes, not just the symptoms.

## Expected behaviour
- The page is centered and readable.
- The product row becomes a vertical layout on narrow screens.
- Clicking **Launch demo** changes the status to `Status: demo launched`.

## Rules
- Before editing, write down what is wrong.
- Use browser DevTools and inspect the console.
- Fix one thing at a time and retest.
- Be ready to explain two fixes and the evidence that led you to them.

## Optional boss level
Add a second button that resets the status. Make sure keyboard focus is visible.
